
# Flashcard Quiz Game

**Flashcard Quiz Game** is a Python-based desktop application that provides an interactive quiz experience using flashcards. It is built using **Tkinter** for the GUI and **SQLite** for local data storage.

## Features

- User sign-up with name and email validation  
- Multiple quiz categories: General Knowledge, Grammar, Sports, Math, Poetry, and Technology  
- Randomly selected questions with multiple-choice answers  
- Timer countdown for each question  
- Score tracking and final result screen with motivational feedback  
- Option to retake the quiz or exit  
- User data and questions stored in a local SQLite database

## Technologies Used

- Python 3.x  
- Tkinter (GUI)  
- SQLite (Database)  

## How It Works

1. **Sign-Up**: Users enter their name and email to start.
2. **Category Selection**: Choose a topic to take a quiz on.
3. **Quiz Interface**: Answer timed multiple-choice questions.
4. **Results**: View your score and get feedback based on your performance.
